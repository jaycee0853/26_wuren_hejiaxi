## 这篇论文解决什么问题

深层神经网络为什么难以训练？

在ResNet之前，人们发现一个反直觉的现象——网络越深效果反而越差。PPT里TA讲到这里的时候说了一句话我印象很深："这不是过拟合，是优化问题。"我一开始不太理解，后来读论文才明白：

- 过拟合是训练集好、测试集差
- 但深层网络是**训练集也变差了**

这说明梯度在反向传播时会越来越小（梯度消失），前面的层几乎学不到东西。不是模型容量不够，是优化器找不到好的参数。

ResNet通过"残差学习"解决了这个问题，让训练上百层的网络成为可能。

---

## 核心创新：残差连接

### 传统网络 vs 残差网络

传统网络让每一层直接学目标映射 H(x)。

ResNet让每一层学"残差"——目标映射和输入的差值：

```
F(x) = H(x) - x    # 学"比输入多了什么"
H(x) = F(x) + x    # 输出 = 残差 + 输入
```

### 为什么学残差更好

我是这么理解的：

1. **学残差更容易**：如果某一层最优的情况是"输入和输出差不多"，那F(x)≈0，网络只需要把权重学成接近0就行。但如果让网络直接学H(x)=x，反而很难——因为要通过一堆非线性激活函数和权重矩阵来拟合一个恒等映射，这本身就很困难。

2. **梯度可以直接传回去**：因为H(x) = F(x) + x，梯度可以通过x这条路径直接传到前面的层，不需要经过F(x)里的权重。这就像给梯度修了一条"高速公路"，解决了梯度消失。PPT里画了个图，从loss开始一层一层往回传，有了残差连接之后梯度可以直接"跳"过去。

3. **更深的层不会变差**：如果更深的层没用，残差连接会让F(x)≈0，相当于恒等映射（输入直接传到输出），至少不会比浅层网络差。所以"越深越差"的现象消失了。

### 残差块结构

```
输入x
  │
  ├─→ Conv → BN → ReLU → Conv → BN    # 主路径，学F(x)
  │                              │
  │                              ↓
  ├───────────────────────→ [+] ←─┘    # 残差连接，F(x)+x
  │                              │
  └────────────────────────────→ ReLU
                                 │
                               输出H(x)
```

这个结构看起来很简单，就是加了一个"+"，但效果非常好。论文里34层的ResNet比34层的Plain Network（没有残差连接）错误率低了不少。

## 网络结构

论文提出了不同深度的ResNet：ResNet-34（34层）、ResNet-50（50层）、ResNet-101（101层）、ResNet-152（152层）。

作为对比，没有残差连接的34层Plain Network在训练集上准确率都比ResNet-34低，而且越深越差。有了残差连接之后，152层的ResNet比34层的还要好。

几个结构特点：全部用3×3卷积核（跟VGG思路一样），每个卷积后接BN层（Batch Normalization），没有用Dropout（BN本身有正则化效果）。

更深的ResNet（50层以上）用了"瓶颈结构"：先用1×1卷积降维，再3×3卷积，再1×1升维。这样3×3卷积在低维空间做，计算量少很多。

## 训练方式

- 图片224×224，从256×256随机裁剪
- Batch Size 256，SGD + Momentum(0.9)，学习率0.1开始loss不降时×0.1
- Weight Decay 1e-4，数据增强用了随机裁剪+水平翻转+标准化

和我作业的对比：ResNet用SGD是因为ImageNet数据量大（128万张），SGD泛化性好。我用Adam是因为训练集小（1298张），Adam收敛快。ResNet没用Dropout因为有BN，我用了Dropout因为训练集小容易过拟合。

## 数据集

主要在ImageNet 2012上验证，1000个类别，训练集128万张，验证集5万张。也在CIFAR-10上做了实验（10个类别，5万训练图片），同样验证了残差连接的效果。

## 我的思考

**1. 残差连接的思想很巧妙**

表面上看只是加了一个"+"，但背后的直觉很深刻——学差值比学完整映射更容易。这让我想到解决问题的时候换个角度可能会简单很多。

**2. "更深的网络反而更差"不是过拟合**

之前我一直以为"更深的网络效果差=过拟合"，但论文里明确指出更深的网络在训练集上准确率也下降了，这说明是优化问题。残差连接解决的是优化问题——让梯度能传回去。这个认识对我理解深度学习很有帮助。

**3. 和我作业的联系**

我的网络只有5层，不需要残差连接。但如果以后做更深的网络（20层以上），残差连接就是必须的了。这次读论文让我理解了为什么ResNet之后几乎所有网络都用残差连接——它解决了深层网络训练的根本问题。

**4. 简单但有效**

残差连接的实现就是一行 `F(x) + x`，但对深度学习的影响巨大。好的创新不一定要很复杂，关键是找到问题的本质。PPT里TA也说过类似的话，大概意思是"有时候最简单的办法反而是最好的"。
