## 作业1：自行车模型

### 第1问 运动学模型

就是给定一个固定的方向盘转角（5度）和车速（30m/s），让车跑起来看看轨迹长啥样。

核心就一句话：车的转弯快慢（横摆角速度）跟车速和方向盘转角有关，公式是

v * tan(方向盘转角) / 轴距

轴距就是前后轮距离，这里lf+lr=4.075m。

然后每过0.01秒更新一下车的朝向角和位置，循环5000次（50秒）就画出来了。

我一开始纠结先更新位置还是先更新角度，试了下差别不大，就按先角度后位置来的。

### 第2问 轨迹跟踪

让车跟着一条正弦曲线走。PPT里讲了纯跟踪（Pure Pursuit），我就用的这个。

思路很简单：往前看一段距离（叫预瞄距离），找到参考轨迹上的那个点，然后算方向盘怎么打才能开到那个点去。

踩坑：
- 预瞄距离设3米，车一直左右晃，跟喝醉了似的
- 设8米又太远了，弯道反应不过来，切出去好多
- 最后试了个5米，效果还行
- 还加了个方向盘限制（正负45度），不然有时候算出来的角度太离谱

### 拓展 动力学模型

这个是选做，我没做。动力学模型比运动学复杂，要考虑轮胎侧偏力，用牛顿第二定律算加速度。代码模板里已经注释掉了。

## 作业2：机器狗找信号源

信号源在(3,3)，狗从(0,0)出发。代价函数是

0.5*(x-3)^2 + 5*(y-3)^2

y方向的系数是x方向的10倍（x方向0.5，y方向5），所以y方向梯度特别陡。

### Q1 梯度下降

就是往梯度的反方向走，每次走一小步。

梯度算出来是 [x-3, 10*(y-3)]，y方向是x方向的10倍。

我试了4个学习率（实际跑出来的数据）：
- 0.01：太慢了，要走797步
- 0.05：还行，157步
- 0.1：快一点，76步
- 0.15：最快，50步就到了

y方向梯度虽然大，但这几个学习率都收敛了。不过如果学习率再大一点（比如0.2），y方向可能就飞了。

### Q2 KKT条件

加了个约束：x+y不能超过4（警戒线）。

拉格朗日函数就是原函数加上一个惩罚项 mu*(x+y-4)。

KKT条件有四个，我一个个列：
1. 对x求偏导等于0：x-3+mu=0，所以x=3-mu
2. 对y求偏导等于0：10(y-3)+mu=0，所以y=3-mu/10
3. mu*(x+y-4)=0，这叫互补松弛
4. x+y<=4，mu>=0

先猜约束激不激活。如果不激活（mu=0），那x=3,y=3，x+y=6>4，违反约束了。所以约束一定激活，mu>0。

由互补松弛，x+y=4，代入：
(3-mu) + (3-mu/10) = 4
6 - 11mu/10 = 4
mu = 20/11

然后x = 3-20/11 = 13/11 ≈ 1.182
y = 3-2/11 = 31/11 ≈ 2.818

验算一下：x+y = 44/11 = 4，刚好在约束边界上，mu也是正的，没问题。

### Q3 用Eigen解KKT

本来想用OSQP库，但Windows上装OSQP太折腾了（MinGW编译的DLL和VS的MSVC不兼容，试了好久跑不起来）。

所以直接用Eigen解KKT矩阵。本质是一样的：把Q1的代价函数加约束x+y<=4，写成QP标准型，然后解KKT方程。

KKT方程是个3x3的线性方程组：
[P  A'] [x]   [-q]
[A  0 ] [mu] = [u]

用Eigen解出来，和Q2手算的KKT结果一模一样（差在浮点精度，大概2e-16）。

这也算搞懂了QP求解的本质——就是解KKT条件。

## 怎么运行

作业1：直接用MATLAB打开m文件运行，会出图。
